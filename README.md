# Minesweeper-Clone

A Minesweeper clone using Python and Pygame
### Game Settings
* 16 x 16 Board Size
* 40 Mines
### Rules
* Right click to place a flag. Left click to dig a tile
* If you finish the game or dig a mine, left click to make a new board
* To close the game, simply close the window

To run the game, run in terminal ```python3 main.py```
